# culinary_assistant-
# AI Кулинарен Асистент: Какво има в хладилника?

**Автор:** Денис Неделчев

---

## 1. Обзор (Overview)
Това е интелигентно уеб приложение, създадено с **Flask** и **Google Gemini AI**. Приложението използва изкуствен интелект за анализ на снимки на хранителни продукти и генериране на персонализирани рецепти, базирани на това, което потребителят има под ръка.

## 2. Основни функционалности
* **Автоматично разпознаване:** Идентифицира продуктите от качена снимка чрез Gemini AI.
* **Генериране на рецепти:** Създава пълни инструкции за готвене на база наличните продукти.
* **Хранителна стойност:** Изчислява приблизителна хранителна стойност (калории) за предложеното ястие.

## 3. Технологичен стек (Requirements)
* **Python 3.11+**
* **Flask** (уеб рамка)
* **Google Generative AI SDK** (за връзка с Gemini)
* **Библиотеки:** `google-genai`, `python-dotenv`, `Pillow`

## 4. Структура на проекта
* `/static/uploads/` – за съхранение на качените изображения.
* `/templates/index.html` – потребителският интерфейс.
* `app.py` – основната логика на приложението.
* `.env` – за сигурно съхранение на API ключа (този файл **не се качва** в GitHub).

## 5. Инструкции за инсталиране и стартиране

1.  **Клониране на проекта:**
    ```bash
    git clone [https://github.com/DNedelchew/culinary_assistant.git](https://github.com/DNedelchew/culinary_assistant.git)
    cd culinary_assistant
    ```

2.  **Създаване на виртуална среда:**
    ```bash
    python -m venv .venv
    ```

3.  **Активиране на средата:**
    * **За Mac/Linux:** `source .venv/bin/activate`
    * **За Windows:** `.venv\Scripts\activate`

4.  **Инсталиране на пакети:**
    ```bash
    pip install flask google-genai pillow python-dotenv
    ```

## 6. Конфигурация на API ключа
Потребителят трябва да получи безплатен ключ от [Google AI Studio](https://aistudio.google.com/).
1.  Създайте файл `.env` в главната папка.
2.  Поставете ключа си вътре: `GEMINI_API_KEY=вашият_ключ_тук`.
*Важно: Уверете се, че `.env` е добавен в `.gitignore` за сигурност.*

## 7. Тестване и употреба
1.  Стартирайте сървъра: `python app.py`
2.  Отворете браузъра на адрес: `http://127.0.0.1:5000`
3.  Качете снимка на продукти и натиснете бутона за генериране, за да получите резултат от AI.

## 8. Справяне с проблеми (Troubleshooting)
* **Грешка 429 (Quota exceeded):** Безплатният план има лимити. Изчакайте 1 минута и опитайте отново.
* **Моделът не е намерен (404):** Проектът ползва `gemini-3-flash`. Ако вашият ключ не го поддържа, сменете модела в `app.py` на `gemini-1.5-flash` или `gemini-2.0-flash`.
