# culinary_assistant-
AI Кулинарен Асистент: Какво има в хладилника?
Автор: Денис Неделчев
Обзор
Това е интелигентно уеб приложение, създадено с Flask и Google Gemini AI. Проектът решава ежедневния проблем с избора на ястие, като анализира снимка на наличните продукти в хладилника и автоматично генерира персонализирани рецепти, включващи хранителна стойност.
Основни функционалности
Приложението изпълнява трите ключови задачи за един модерен кулинарен помощник:
Автоматично разпознаване: Използва Computer Vision (чрез Gemini AI), за да идентифицира продуктите от качената снимка.
Генериране на рецепти: Създава пълни инструкции за готвене, базирани единствено на разпознатите съставки или добавени от потребителя предпочитания.
Хранителна стойност: AI изчислява приблизителните калории и макронутриенти за предложеното ястие.
Технологичен стек (Requirements)
Език: Python 3.11+
Рамка: Flask (Web Framework)
AI SDK: google-genai (най-новата версия на Google AI SDK)
Библиотеки:
Pillow – за обработка на изображения.
python-dotenv – за сигурно управление на API ключове.
Bootstrap 5 – за модерен и адаптивен интерфейс.

 Инсталиране и стартиране
Следвайте тези стъпки, за да стартирате проекта локално:
Клониране на проекта:
Bash
git clone https://github.com/DNedelchew/culinary_assistant.git
cd culinary_assistant
Създаване на виртуална среда:
Bash
python -m venv .venv
Активиране на средата:
За macOS/Linux: source .venv/bin/activate
За Windows: .venv\Scripts\activate
Инсталиране на пакети:
Bash
pip install flask google-genai pillow python-dotenv
Конфигурация на API ключа
За да работи AI функционалността, трябва да получите ключ от Google AI Studio:
Посетете aistudio.google.com.
Генерирайте нов API ключ.
В главната папка на проекта създайте файл .env.
Поставете ключа си вътре:
Plaintext
GEMINI_API_KEY=вашият_ключ_тук
Важно: Никога не качвайте своя .env файл в публични хранилища!
Тестване и употреба
Стартирайте сървъра:
Bash
python app.py
Отворете браузъра на адрес: http://127.0.0.1:5000
Качете снимка на продукти (например домати, яйца и сирене).
(Опционално) Добавете текст като "Искам здравословна рецепта".
Натиснете "Генерирай рецепта" и изчакайте AI анализа.
Справяне с проблеми (Troubleshooting)
Грешка 429 (Quota exceeded): Безплатният план на Google има лимити. Ако получите тази грешка, изчакайте 1 минута и опитайте отново.
Моделът не е намерен (404): Приложението е настроено да използва gemini-3-flash. Уверете се, че имате достъп до най-новите модели в AI Studio.
Снимката не се качва: Проверете дали папката static/uploads съществува и имате права за запис в нея.
Грешка: "Сървърът е натоварен" или 404: Този проект е оптимизиран за модел gemini-3-flash. Ако вашият API ключ не поддържа този модел или ви дава грешка, отворете app.py и заменете името на модела на ред 46:model="gemini-3-flash"  : Сменете на "gemini-1.5-flash", ако е необходимо.
